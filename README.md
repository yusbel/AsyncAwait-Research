# AsyncAwait — Research

Research spikes and hypothesis tests for [AsyncAwait](https://asyncawait.ca).
Each spike lives in its own folder with a README that states the hypothesis,
how the spike was built, and what was actually verified. Spikes are disposable
by design — they answer a question, they don't become the product.

## Spikes

| Folder | Question |
|---|---|
| `course-planner-spike/` | Can a conversational AI agent generate a custom course schedule as JSON? |
